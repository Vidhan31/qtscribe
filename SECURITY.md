# Security policy

## Supported versions

Only the latest release and the `main` branch receive security updates.

| Version | Supported |
| ------- | --------- |
| main    | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Do not report security vulnerabilities in public issues or discussions.

Report vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/Vidhan31/qtscribe/security/advisories/new).

Include:
- Issue description and security impact
- Steps to reproduce or a proof of concept
- Affected version and OS environment

### Response timeline

- Maintainers acknowledge reports within 48 hours.
- Maintainers send a status update with next steps within 5 business days.
- After verifying a fix, maintainers release a patch and publish a coordinated advisory.
